VLAN 1991 1992 1993 1994 1995 1996 WAN Host
Use Device provisioning ports (isolated) WAN Host

WORKFLOW

1 Connect the device to port 1-6
2 The switch isolates the device on a dedicated VLAN
3 The host detects the link and identifies the device
4 The host uploads firmware and configuration
5 Check the web UI for status

TROUBLESHOOTING

No detection?Check cable, power, link LED on switch
Wrong firmware?Check firmware dir on Pi
Auth failed?Device has non-default password
Stuck?Restart provisioner-web service
Each port is ISOLATED - devices cannot see each other during provisioning
